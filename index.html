3D CFD熱流体ソルバの基礎原理・メッシュ構築・計算手順

本シミュレータでは、ノズル吹出し口径（Ø85mm等）の噴流シア層や境界層を忠実に解像するため、非均一ストレッチ構造格子（tanh clustering）と埋め込みサブグリッド（Embedded Subgrid）を採用しています。

📌 非均一ストレッチ格子の定式化 (Roberts 1971 型)

等間隔パラメータ $\xi \in [0, 1]$ に対し、双曲線正接関数 $\tanh$ を用いて特定領域へ格子点を集中配置します。

// 中心集中型 (x, y軸: ノズル軸心 cx=cy=1.0m 付近を密に配置)
s(ξ) = 0.5 × [ tanh(β_xy × (2ξ - 1)) / tanh(β_xy) + 1 ]
x_face(i) = s(i / NX) × L

// 片側集中型 (z軸: 天井ノズル吹出し口 z=2.0m 付近および床面を密に配置)
s_z(ξ) = 1.0 - tanh(β_zt × (1 - ξ)) / tanh(β_zt)

これにより、一様格子（約31mm幅）に比べてノズル直下の局所最小格子幅は約 h_min ≈ 2.5mm（均一格子換算で約800×800×800相当）まで高解像度化され、ノズル開口部Ø85mmを直径あたり約34点で解像します。

🧩 実寸ジオメトリ埋め込みサブグリッド (Embedded Subgrid Sampling)

ノズル高さ領域（z = 1.82m 〜 2.0m）のセルでは、実寸のテーパー内外径・中心シリンダー（図2）に対し、各セルを NOZZLE_SUBSAMPLE³ (12×12×3 = 432点) で細分サンプリングし、開口率 inletFrac を算出します。

流路開口セル (INLET)

ノズル内径の内側に位置するサンプル点。開口率 inletFrac に応じて吹出し速度を按分し、多孔質境界として実流量を保存。

ノズル固体壁 (WALL)

ノズルテーパー胴体壁（内外径の間）および図2の中心シリンダー。速度ゼロのNo-slip壁面境界条件を適用。

ノズル外気 (FLUID)

ノズル胴体の外側の空間。通常の室内空気として扱い、天井面（z=2.0m）のみ固体壁境界を適用。

本ソルバは、非圧縮性粘性流体の支配方程式（Navier-Stokes方程式、連続の式、エネルギー方程式）を有限体積法（Finite Volume Method）により離散化しています。

🌊 支配方程式 (Governing Equations)

// 連続の式 (非圧縮条件)
∇ · u = 0

// ナビエ・ストークス方程式 (運動量保存則 + Boussinesq浮力)
∂u/∂t + (u · ∇)u = - (1/ρ₀) ∇p + ν ∇²u + g + β (T - T_ref) g

// エネルギー方程式 (熱輸送方程式)
∂T/∂t + (u · ∇)T = α ∇²T
有限体積法 (FVM) フラックス収支

各直交セルをコントロールボリューム（検査体積）とし、隣接面を通過する質量・運動量・熱量の流出入（フラックス）を厳密に保存します。

移流項: 風上差分 (Donor-Cell)

流速の正負に応じ、流速が流れてくる上流側の物理量を参照することで、高レイノルズ数域でも数値振動（ギブズ現象）を防ぎ安定性を確保します。

拡散項: 非均一2次精度ラプラシアン

セル間隔が異なる非均一格子に対応するため、局所格子幅（hE, hW, hN, hS, hU, hD）に基づく非対称中心差分で2次精度を維持します。

Boussinesq浮力近似

冷気噴流（23.5°C）と室内空気（34.0°C）の温度差による密度変化を、運動量式の浮力項 β(T - T_ref)g として取り込み、冷気の下降沈降流を再現。

非圧縮性流体では圧力項と速度場がカップルするため、Chorinの射影法（Fractional Step Method / Projection Method）を用いて1時間ステップごとに分離解法を実行します。

Step 1
仮速度 u* の計算 (予測ステップ)

圧力勾配項を除いた運動量方程式を陽的に時間発展させ、移流・粘性拡散・重力・Boussinesq浮力を反映した仮速度 u* を求めます。

u* = uⁿ + Δt [ - (uⁿ · ∇)uⁿ + ν ∇²uⁿ + g + β(Tⁿ - T_ref)g ]
Step 2
仮速度の発散計算 ∇ · u*

仮速度 u* は非圧縮条件（発散ゼロ）を満たさないため、セル中心において局所発散を算出します。これが圧力ポアソン方程式のソース項となります。

RHS = (ρ₀ / Δt) ∇ · u*
Step 3
圧力ポアソン方程式の求解 (ヤコビ反復)

非均一格子の係数行列に基づき、楕円型ポアソン方程式 ∇²p = RHS をヤコビ反復解法（32反復/ステップ）で高精度に解きます。

∇²p = (ρ₀ / Δt) ∇ · u*
Step 4
速度場の補正 (射影ステップ) & 温度更新

得られた圧力場の勾配 ∇p を仮速度 u* から差し引くことで、完全に発散ゼロ（非圧縮条件）を満たす次ステップの速度場 uⁿ⁺¹ へ射影補正します。同時に温度場も更新します。

uⁿ⁺¹ = u* - (Δt / ρ₀) ∇p (このとき ∇ · uⁿ⁺¹ = 0)
Tⁿ⁺¹ = Tⁿ + Δt [ - (uⁿ · ∇)Tⁿ + α ∇²Tⁿ ]
