# 3D CFD 熱流体シミュレータ (WebGPU / FVM)

WebGPU を活用したブラウザ完結型の 3次元有限体積法 (FVM) 熱流体シミュレータです。
ノズル（吹出し口）からの冷気噴流と室内の熱移動・気流速度場・圧力場をリアルタイムに連成解析・可視化します。
WebGPU 非対応ブラウザでは WebGL (Three.js) による CPU フォールバックモードで動作します。

## 特徴
- **リアルタイム FVM 計算**: 構造格子によるナビエ・ストークス方程式＋エネルギー方程式の高速解法
- **ノズル内部構造の精密再現**:
  - 図1: スロート整流円筒付きコーンノズル
  - 図2: 上部中空コーン＋下部円筒整流筒の二重管ノズル
  - 図3: 平板コア・整流円筒付きディフューザー
  - 図4: ベルマウス型整流ノズル
- **多彩な可視化機能**:
  - 速度ベクトル表示（断面厳密フィルタリング・3D間引き表示）
  - 断面スカラーセル表示（温度 / 速度 / 圧力）
  - コンター表示
  - 3Dメッシュワイヤーフレーム表示
  - ノズル部の拡大フォーカス機能
- **GPU / CPU ソルバーのシームレス切替**
